# HandHold Frontend

React + Vite frontend for the HandHold student mentoring platform.

## Included pages
- Landing page, sign-in/sign-up, student onboarding, student dashboard
- My Mentor, Goals & Progress, Meetings, Messages, Feedback
- Profile & Settings (personal details, learning preferences, account information)
- Mentor dashboard, My Students, and student detail route

## Run locally
1. Install Node.js LTS (if not already installed).
2. Open a terminal in this `frontend` folder.
3. Run `npm install`
4. Run `npm run dev`
5. Open the localhost URL shown by Vite.

## Important demo notes
Some screens use browser/local component state and are frontend demonstrations. Real authentication, mentor assignment, messages, meeting approval, and persistent API syncing need to be connected to your team's backend. Profile settings are saved locally in the browser for this demo.
